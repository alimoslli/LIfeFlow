# Adding the LifeFlow brand kit to Claude

1. In Claude (claude.ai or the app): Settings, then Capabilities. Make sure "Code execution and file creation" is on.
2. Under Skills, choose "Upload skill" and pick `lifeflow-brand.zip` (the whole zip, don't unzip it).
3. Turn the skill on. From then on, ask Claude for any LifeFlow ad, Reel, caption or post and it follows these rules
   and uses these files. You can also say "use the LifeFlow brand skill" to be sure.

Using Claude Code instead? Unzip the folder into `~/.claude/skills/` so the path is `~/.claude/skills/lifeflow-brand/SKILL.md`.

Editing videos yourself (CapCut, Premiere)? Install the fonts in `assets/fonts` and use the files in `assets/` directly.
The one-page overview is `assets/LifeFlow-brand-basics.png`.
